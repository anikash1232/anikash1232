### Graphics — C++

**[2d-rasterizer-blending](https://github.com/anikash1232/2d-rasterizer-blending)** — A 2D
rasterizing graphics engine written from scratch, no graphics library. Implements the full
Porter-Duff compositing model — all twelve blend modes over premultiplied pixels — with
span blending templated on the mode so the dispatch switch folds away at compile time.

**[2d-rasterizer-shapes](https://github.com/anikash1232/2d-rasterizer-shapes)** — Canvas
primitives and polygon filling built on the same engine.
